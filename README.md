# Rustichelli Color

Sito vetrina di Rustichelli Color Srl, colorificio a Lugo, Faenza, Cervia e Riccione.

Il sito è statico: basta `index.html` con la cartella `assets/`. Si pubblica con GitHub Pages dal branch `main`.

## Da completare

- Foto e video reali (cerca `DA FORNIRE` in `index.html`)
- Numeri WhatsApp delle quattro sedi
- Email o servizio per l'invio del modulo preventivo
- Profilo Instagram

Il master prompt del progetto è in `docs/master-prompt-rustichelli.md`.
